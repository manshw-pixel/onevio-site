FAQ

Questions teams ask

What is a customer health score?

A number from 0 to 100 that sums up how an account is doing. OneVio builds it from five inputs: product usage (30%), customer sentiment (20%), support tickets (15%), engagement recency (20%) and NPS (15%). Admins can change the weights in Settings. Each score falls into a Green, Yellow or Red band, and a drop in health shows up in the notification bell.

How is NRR different from GRR?

Both measure how much revenue you kept from existing customers over the last 12 months. NRR (net revenue retention) includes expansion, so it can go above 100%. GRR (gross revenue retention) counts only contraction and churn, so it never goes above 100%. OneVio counts an account as an existing customer once it started more than 365 days ago; revenue from newer customers shows as new business in the ARR bridge, not as retention.

Can I import accounts from Excel or CSV?

Yes. Save your spreadsheet as CSV and import it from the Accounts page. OneVio reads YYYY-MM-DD, DD-MM-YYYY and MM-DD-YYYY dates, and if a file mixes day-first and month-first dates it imports nothing and tells you why, rather than guessing. You can export your accounts to CSV at any time.

Does OneVio support INR and other currencies?

Yes. Each account's ARR can be in Indian rupees (INR), US dollars (USD) or Philippine pesos (PHP). Dashboard totals, NRR and GRR are converted to USD using the conversion rates set in Settings, so every number compares like with like.

Is each company's data kept separate?

Yes. Each company gets its own workspace. Row-level security in the database keeps one workspace's accounts, tasks and activities out of every other workspace, so the separation does not rely on the screen hiding anything.

Can I disable a user's access immediately?

Yes. An admin can disable a user at any time. The database stops serving that user's data straight away, without waiting for their session to expire, and an admin can re-enable them later.

Does it work on mobile?

Yes. OneVio runs in the browser and adapts to phone screens, so you can check an account, log an activity or tick off a task between meetings. There is no app to install.
